# GitHub for Healthcare Workers: A Beginner Manual

Plain English, step-by-step guidance for healthcare workers who want to use
GitHub to document protocols, share templates, and version-control shift
sheets. No coding required. Privacy-safe by design.

Written in the spirit of Dylan Asdale's *The Massive AI Manual* and the
ASDALE DYNAMICS, LLC hub site (dylanasdale.github.io): AI and tech explained
"like a friend would" — clear, warm, never condescending.

## Who this is for

Nurses, medical assistants, care coordinators, administrators, and anyone else
working in healthcare who keeps paper or digital documents and wants a safer,
more organized way to track changes. You do not need to be technical. You do
not need to write code.

## What is inside

**docs/** — The full beginner manual in Markdown:

- `01-getting-started.md` — What GitHub is and why it matters in healthcare
- `02-github-account.md` — Setting up your account (no personal data required)
- `03-documenting-protocols.md` — Writing and version-controlling clinical protocols
- `04-sharing-templates.md` — Sharing templates with your team
- `05-version-controlling-shift-sheets.md` — Tracking changes to shift sheets
- `06-privacy-and-safety.md` — Keeping patient information out of GitHub
- `glossary.md` — Plain-English definitions of GitHub terms

**site/** — The same manual as a static HTML website you can open in any
browser. No server, no install, no internet required once you have the files.

## Privacy and safety (read first)

This guide is for education and organization only. It is not medical advice.
**Never put patient names, medical record numbers, dates of birth, or any
other patient information in GitHub.** GitHub is not a HIPAA-compliant place
to store health records. See `docs/06-privacy-and-safety.md` for the full
privacy rules.

## How to use this manual

1. Start with `docs/01-getting-started.md` (or open `site/index.html`).
2. Work through the chapters in order. Each one is a short, step-by-step task.
3. Practice on a test repository with fake data before using GitHub for real
   work documents.
