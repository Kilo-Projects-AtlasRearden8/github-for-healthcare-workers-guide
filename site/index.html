GitHub for Healthcare Workers

Plain English · Step by step · No code required

This manual shows healthcare workers how to use GitHub to keep work documents organized and safe: clinical protocols, shared templates, and shift sheets. You do not need to write code, and you do not need to be technical. Everything here uses buttons and menus on the GitHub website.

1. Getting started

What GitHub is, why healthcare teams use it, and the three ideas you need: repositories, commits, and branches.

2. Your GitHub account

Create an account, sign in, turn on two-factor authentication, and keep your profile privacy-safe.

3. Documenting protocols

Create a protocol repository, write a protocol in plain text, save changes, and review older versions.

4. Sharing templates

Build a template repository for shift reports, checklists, and sign-out sheets your team can copy and reuse.

5. Version-controlling shift sheets

Keep every version of a shift sheet, see what changed, and fix mistakes by going back to an older copy.

6. Privacy & safety

Read this first. What never belongs on GitHub, how to keep repositories private, and the newspaper test.

Glossary

Plain-English definitions of GitHub terms used throughout this manual.
Privacy first

Never put patient names, medical record numbers, dates of birth, or any other patient information on GitHub. GitHub is not a HIPAA-compliant place to store health records. Read Chapter 6 before you upload any workplace document.
